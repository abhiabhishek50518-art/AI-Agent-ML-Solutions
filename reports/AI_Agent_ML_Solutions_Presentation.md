## Slide 4: System Architecture
```
User Query (Natural Language) ➔ QueryParser Intent Classifier
   ├➔ Revenue & Product Tool ➔ Pandas Aggregation Engine
   ├➔ Sales Forecast Tool ➔ Random Forest Regressor
   ├➔ Recommendation Tool ➔ Cosine Similarity Matrix
   └➔ Customer Segment Tool ➔ RFM K-Means Clustering
```

---

## Slide 5: Core Machine Learning Models
1. **Collaborative Filtering**: Item Cosine Similarity matrix predicting unrated product ratings ($1.0$ to $5.0$).
2. **Sales Forecasting**: Time-series Random Forest model predicting daily revenue up to 60 days ahead ($MAE < \$150$).
3. **RFM Segmentation**: K-Means ($k=4$) categorizing accounts into *VIP Champions*, *Loyal Spenders*, *Steady*, and *At-Risk*.
